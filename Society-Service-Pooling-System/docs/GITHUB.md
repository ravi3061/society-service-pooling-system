# SSPS GitHub Publishing Checklist

Suggested repository name: `society-service-pooling-system`.

## Before publishing

- Install Git and check `git --version`.
- Use the extracted project folder as the repository root, not the ZIP file.
- Ensure `.gitignore` exists before staging changes.
- Commit source, documentation, sources.txt, run.bat and the VS Code project settings.
- Exclude local data, compiled output, passwords, tokens and personal records.
- Ignore rules do not remove files that were already tracked.
- Compile and follow the demo before describing the project as tested.

## Publish using VS Code

1. Open the full project folder.
2. Open Source Control and choose Initialize Repository.
3. Review and stage intended files.
4. Commit with a message such as `Add modular SSPS prototype`.
5. Choose Publish to GitHub, sign in and select visibility.
6. Use the suggested repository name or another appropriate name.

If asked, configure your own Git author name and email. Consider your GitHub-provided no-reply email for privacy.

For later changes, review, stage, commit and push. GitHub stores this desktop application's source; it does not make the app run in a browser.

No licence has been selected automatically. Choose a licence deliberately before offering reuse under specific terms.
